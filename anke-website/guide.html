GET STARTED

第一件事，
从这里开始。

选择适合当前任务的工作方式。

01 · 获取应用与更新

打开 Anke 发布页，查看可用安装包与发布说明。仓库访问权限与安装包可用性以发布页为准。

02 · 用 Agent 完成任务

在设置中配置模型账户，回到工作区选择项目或新建任务。输入目标并提供资料，查看工具执行记录和产出文件。需要调整时先停止，再说明后续要求。

03 · 用 Bot 持续协作

切换至 Bot，按工作、生活、住房与物业分类选择成员或服务。查看会话、整理事项，按需要绑定账户与连接器。

04 · 查看住房与租金

在住房研究台选择样本与过滤条件，展开租金、地址、来源和日期。查看项目比较与原文，保留计算口径。

05 · 查看结果与预览

在任务记录中打开产出文件。HTML 结果可在浏览器工作区预览；离开 Agent 切换至 Bot 后，原有预览面板应当收起。

06 · 账户与服务连接

邮件、语音、物联网和外部服务需要对应账户或设备连接。查看应用内连接状态和业务回执，按实际配置使用。
