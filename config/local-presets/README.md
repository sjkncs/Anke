# 本地配置快照

本目录保存 2026-11-15 从当前本地 ANKE 导出的配置快照，包括 Bot 角色和指令、服务分类、模型绑定、协作房间、工作区、模型服务、模型目录、界面偏好和 Bot 连接器。

`latest.sanitized.json` 是备份格式，当前没有自动导入器；不能将它直接替换为运行中的数据库或 team.json。个人密钥、授权令牌及机器路径分别替换为 `${REQUIRED_CREDENTIAL}` 和 `${LOCAL_PATH}`。其他电脑需要重新填写凭证及有效路径，连接成功与否仍须实际验证。

瑞幸与麦当劳来自 Bot 连接器记录。独立 `.agents/servers` 服务器文件本次检索为零，不能据此宣称所有外部 MCP 均已接入。此快照不包含聊天记录、会话历史、长期记忆、登录状态、浏览器 Cookie 或凭证库。

`sync-report.json` 记录导出数量和源文件扫描拦截清单。被拦截的源文件保留 GitHub 基线版本，未用可能含凭证的本地副本覆盖。安装包、模型权重、运行数据库和视频未纳入本次源码提交。

本次同步提供源码与配置备份，不代表已完成安装包构建、自动配置恢复或跨机器运行验收。
