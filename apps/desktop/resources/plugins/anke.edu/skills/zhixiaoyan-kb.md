# 智小研公开知识库（本地镜像）

## 什么时候用

- 用户问「智小研」「智小舍」「PKU OpenAgent」上某个智能体是做什么的
- 需要按学科/学段/学校/作者挑一个智能体来做教学任务
- 需要知道某个智能体公开了哪些知识库文件（只有文件名，没有正文）
- 需要把答案追溯到 spising.cn 的原页

## 怎么调

工具 `ZhixiaoyanKnowledge`，四种 action：

```json
{"action":"search","query":"骆驼祥子 整本书阅读","limit":5}
{"action":"agent","slug":"ly-iy5p0s"}
{"action":"list","subject":"语文","grade":"七年级"}
{"action":"stats"}
```

## 必须遵守

1. **只读公开元数据**：`files` 是平台公开的文件清单，正文没有镜像。回答时要说清这一点，不能假装读过正文。
2. **保留来源**：每条结论带上 `source`（原页 URL）。
3. **不编造统计**：使用人数/对话数来自快照，注明「快照 2026-11-13」。
4. 用户要知识库正文时，请对方用自己账号从原平台导出，放进 `data/imported/<slug>__<标题>.md`，重建索引后再检索。

## 覆盖范围

- 86 个公开智能体（语文 54、数学 9、历史 3、班会 3、地理 2、生物学 2、英语 2、物理 1、化学 1 等）
- 46 个智能体公开了知识库文件，共 374 条文件条目、346 个不重复文件名
- 85 个智能体在平台侧启用了数字人形象（本地复刻站用 Canvas 重建，未使用平台素材）
