# 住房工作台展示

个人版：总览、人才选房、租金看板、市场租金、项目比较、地图街景、租金动态。
企业版：总览、候选人画像、人才选房、政府与高校房源、住小智、租金看板、地图街景、租金动态。
政府板块：总览、政府与高校房源、候选人画像、住小智、租金看板、市场租金、项目比较、调租测算、地图街景、租金动态。

版本仅组织现有工具，不代表账号授权。选择保存在当前浏览器；命令直达被隐藏的工具时自动切换到包含该工具的版本。

来源栏显示当前样本来源及数量、记录类型和记录日期。发布机构缺失时按原文域名显示来源网站；不得推断具体发布机关。地图表格缺失地址或坐标时明确标注，定位结果另展示检索来源及坐标系。

调租测算展示四步操作说明、输入单位和计算公式。默认参数仅为情景示例，不是正式政策。

验证：`node --test visual-ui.test.cjs query.test.cjs rent-change-ui.test.cjs`。浏览器测试使用合成样本，覆盖版本切换、字段缺失、来源展示、测算联动、筛选、图表读数与拖动。桌面真实样本另检查来源和卡片几何尺寸。
