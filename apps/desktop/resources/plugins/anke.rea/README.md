# Local REA bridge

Uses the verified local rea-agents 6.4.0 install at E:/tools/rea-6.4.0.
The absolute script argument is machine-local configuration. Relocated machines
must install the pinned package and update this argument. No package download
occurs at tool-call time. The standard host MCP permission gate remains active.
MCP doctor passed initialization, 170 tools, 6 prompts and binary_session.
Native disassembly engines are not installed by this integration.
